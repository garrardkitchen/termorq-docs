Killer Free features

These are in Free, and Pro includes them too.

  1. 1

    Your forges in the terminal New

    Connect GitHub, GitLab or Azure DevOps with a read-only token kept in the OS keychain. @work lists your reviews, pull requests and assigned work; the Todos page collects what your watchers find (Ctrl+Shift+O); a CI chip shows the branch's latest run and opens job logs; Start work makes a branch from a ticket; and @run offers the tasks a repository defines. Free connects one forge.

    Forges overview · @work · Todos · CI status · Start work · Repo runbooks
  2. 2

    Endpoints grouped by API and tag New

    The Library's Endpoints view opens on Recent, Favourites, then a group per API split by tag, with counts. Search ranks matches as you type and takes filter words such as api:billing method:post tag:invoices, shown as chips. @endpoint lists each API as a folder, and @docs turns a saved API into markdown docs.

    The Endpoints view · Filter words · @endpoint folders
  3. 3

    Coloured tags New

    Tag an endpoint with chips. The tag field suggests tags you already use, most used first. Each tag keeps the same colour everywhere: on rows, in group headers, in the sidebar, and in the search box.

    Tags on an endpoint
  4. 4

    Call MCP tools and saved endpoints from the prompt

    Type @tool search --query tea or @endpoint Get user --id 1. Ghost text completes endpoint names, and tool names on a connected server, then their parameter flags. A tool that is not connected yet is found on your saved servers and connected for you. The tool form recalls your last 10 argument sets, leaving out anything that looks like a secret.

    @tool · @endpoint
  5. 5

    Import an OpenAPI schema

    Turn an OpenAPI 3 or Swagger 2 file, JSON or YAML, into an API connection and its endpoints. Postman, Insomnia, and a pasted curl work too. Pick the endpoints to keep; credentials are never imported.

    Import and export
  6. 6

    Share your setup with colleagues

    Export API connections and endpoints (.aitapi), MCP servers (.aitmcp), and collections (.aitcol) as password-encrypted files a colleague imports, with a preview before anything is replaced. Or export endpoints as OpenAPI or Postman with secrets replaced by placeholders.

    Share a file · OpenAPI and Postman export
  7. 7

    Highlight and alert rules New

    Colour output that matches saved text or a regex, and send a desktop notification on a match. Mask in notifications is on by default, so an alert names the rule and tab but never shows the matched line. Free applies three rules; Pro keeps up to 50.

    Highlights and alerts
  8. 8

    Drop-down window New

    A global shortcut slides Termorq down from the top of the screen in any app. Press it again to hide it.

    Drop-down window
  9. 9

    Report an AI issue New

    Flag an AI response, or type @report. The report opens in your email app and a copy is saved. Your API key is never included.

    Report an AI issue
  10. 10

    Inline images New

    See iTerm2 and Sixel images, such as chafa or imgcat output, in the scrollback, and images in API and MCP results. Drop an image file on a tab to show it there.

    Inline images

Killer Pro features

Pro adds these to everything in Free. See the Free and Pro comparison.

  1. 1

    Workflows that keep the terminal free New

    Build a sequence on a full-window page or in YAML. Run code, HTTP, MCP, and your own model from a schedule, a local x-api-key hook, or a Telegram chat. Decisions, loops, and declared properties pass forward. Each run keeps its own folder. Secrets stay in the OS keychain.

    Build a workflow · Triggers and runs
  2. 2

    Explain a failed job or command, and every forge at once New

    Explain sends the end of a failed CI log, or a failed command with its last 40 output lines, to your own AI connection with secrets masked first, and shows the likely cause and a fix that only goes into the prompt. Pro also connects any number of forges and hosts, and can run a command when a watcher fires, after asking.

    Explain failure · Explain a failed command · Run on trigger
  3. 3

    Markdown runbooks New

    Open a .md file with @md, or drop it on the window. Run its shell, PowerShell, Python, JavaScript, TypeScript, or C# blocks one at a time or with Run all. Output streams in under each block.

    Markdown runbooks
  4. 4

    SSH connections, and typing into every SSH tab at once New

    Save SSH hosts or import them from ~/.ssh/config, then open each in a tab. Browse and copy remote files over SFTP and forward local ports. Ctrl+Alt+Shift+B sends what you type to every open SSH tab, so one command reaches every server.

    SSH connections · Sessions and files · Type into all SSH tabs
  5. 5

    Record and replay a tab session New

    Record a tab as an asciinema .cast file with secrets masked. Replay it in the app, export it, or start and stop a recording from the tray.

    Recording and replay
  6. 6

    AI Agent on your own OpenAI-compatible model

    Connect Azure OpenAI, OpenAI, or a compatible server such as Ollama or LM Studio. Agent can call your MCP tools and saved APIs; you approve each call.

    Model connections · Agent in the prompt
  7. 7

    A team workspace you can review

    Share API, MCP, endpoint, and collection definitions with your team through a git folder. @workspace save writes pretty JSON under .ai-terminal/ without secrets. You commit the diff yourself.

    Team workspace
  8. 8

    Web Check from the tray

    Schedule checks for saved APIs and MCP tools and read their history. Start or stop it and open its output from the Windows notification area, macOS menu bar, or Dock.

    Explore Web Check

Bash, zsh, PowerShell, and WSL in tabs and split panes, with an interactive PTY when a program needs a keyboard. Pin, reorder, and maximise tabs, and type into both split panes at once with Ctrl+Alt+B (Cmd+Option+B on macOS).

Why Pro includes termorq-cli

Same engine

termorq-cli calls through the app library. A check that fails in the terminal fails in CI.

Secrets stay out of the file

The workspace stores a name and a vault reference. The value arrives as AIT_SECRET_… or from Azure Key Vault or 1Password.

A result your forge already understands

Text for a person. JSON or YAML for a script. JUnit for GitHub, GitLab, and Azure DevOps.

Five things worth learning first

1

One prompt for four kinds of work

Type a shell line, @endpoint, @tool, or @chat. The scrollback marks which one ran, how long it took, and the HTTP status.

2

Pro: a collection is a runbook

Favourites run first. Captures fill {{name}} on later lines. A failed check, a non-zero exit, or Ctrl+C stops the run in the app.

3

Secrets are not in the git diff

Keys go to the OS keychain. A team folder keeps akv:// and op:// references. Save refuses a file that still contains a token.

4

Pro termorq-cli is that runbook, headless

Every subcommand, the secret rules, and a pipeline for GitHub, GitLab, and Azure DevOps.

A workspace your team can review
